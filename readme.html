事项反馈系统 IFMS

内部部署的轻量事项收集、多人反馈与跟踪系统。本文根据当前代码、配置和已确认需求整理。

FastAPI + Vue 3SQLite + AlembicJWT Bearer Token
系统定位技术配置功能范围角色权限本地启动相关文档

系统定位

支持“发起事项 → 指派参与人 → 收集反馈 → 汇总跟踪”的内部流程，用于替代微信群、Excel 和邮件中的重复催收及人工统计。

系统已正式包含 Excel 表格协作：上传模板、在线填写单元格、自动保存并导出汇总表。所有登录用户均可查看和导出表格。

技术与运行配置

层级当前配置
后端Python、FastAPI、SQLAlchemy、Alembic、SQLite
前端Vue 3、Vite、Element Plus、Axios
鉴权JWT Bearer Token，默认有效期 60 分钟
数据库backend/feedback.db
附件项目根目录 uploads/，当前经 /uploads/* 静态访问
地址前端 http://localhost:5173；API http://127.0.0.1:8000；文档 /docs
生产环境必须配置 JWT_SECRET_KEY；未设置时会使用仅适合本地开发的默认密钥。

已实现能力

用户与认证管理员可管理、删除、导出用户；登录用户可取得用于指派与私有分组的安全用户目录。
事项管理所有登录用户可创建自己的事项；支持附件、参与人分配、筛选、详情、更新、删除与 CSV 导出。
反馈闭环个人待办、提交/修改反馈；所有参与人完成后自动结束事项。
分组与统计组织分组和私有个人分组；个人分组仅创建者与管理员可见；管理员页默认折叠到“用户分组”。
表格协作上传 .xlsx（10 MB、最多 200 行）、网页编辑、全员查看与导出 Excel。
运维工具Alembic 迁移、健康检查、离线打包；不提供邮件、企业微信等外部提醒。

角色与权限

角色主要权限
admin用户、日志、全量事项/统计/导出；管理全部个人和组织分组；编辑、删除所有表格。
creator / feedbacker创建自己的事项、选择参与人；仅查看本人相关事项；创建和维护自己的个人分组，其他人的个人分组不展示；查看、导出协作表格。
服务端根据 JWT 中的当前用户执行归属校验；前端菜单只负责展示，所有登录用户均可打开“新建事项”和“分组管理”。

本地启动

pip install -r requirements.txt
cd backend
alembic -c alembic.ini upgrade head
cd ..
python -m uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000

# 另一终端
cd frontend
npm install
npm run dev

空库可运行 python backend/init_users.py 生成演示用户。该脚本会创建 admin / 123，仅可用于本地演示，首次使用后应立即改密或改用 CSV 导入。
