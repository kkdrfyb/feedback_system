# MCP 使用建议（本项目）

## 是否需要 MCP
- 结论：**不是必须**，但对长期维护有帮助。
- 原因：本项目主要是本地代码与本地 SQLite，基础开发可直接用文件系统和命令行完成。
- 适用场景：当你希望把数据库查询、Git 元数据、统一工具入口标准化给 agent 使用时，MCP 更有价值。

## 建议最小集
- `filesystem`：读取/修改仓库文件。
- `sqlite`：只读查询 `backend/feedback.db` 做排查。
- `git`：查看分支、diff、提交上下文。

## 风险提示
- 生产环境建议对数据库 MCP 使用只读模式。
- 不要在 MCP 配置里硬编码生产密钥。

- 示例配置：`mcp/mcp.config.example.json`
